# Telegram Automations 🤖

A personal Telegram bot built with Python for everyday automations.

## Features

- 🟩 `/wordleanswer` — Get today's Wordle answer

## Tech Stack

- Python
- python-telegram-bot
- Requests
- GitHub

## Setup

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
BOT_TOKEN=your_bot_token
CHAT_ID=your_chat_id
```

Run the bot:

```bash
python src/bot.py
```
